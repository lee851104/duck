# 商家介面簡化

使用者已要求實作四點：商品首頁、照片／品名／售價／可售數量卡片、詳細資料按需展開及設定收納、集中盤點表格。

- 主要導覽為「管商品、處理訂單、匯出資料」，設定在頂部且手機可用。沿用既有訂單管理入口。
- 首頁直接顯示商品卡，保留分類、搜尋、待補貨、未盤點篩選；原分類內照片優先。卡片本身可點，只有照片、名稱、售價、可售數量，不堆疊操作按鈕。
- 進貨、出貨、改價放在點開的商品面板；批次（含進價）與異動紀錄由明確的按鈕按需展開。整體使用米白、橄欖綠與暖黃。
- 商品頁有「商品卡片／集中盤點」切換。盤點逐批次顯示帳面實體數量，不能拿扣除訂單預留後的可售數量當盤點基準。輸入空白表示未填，0 是有效盤點值。
- 草稿在分頁、篩選、視窗縮放與模式切換時保留；頁面重載前提醒未儲存。一次儲存所有已填列，全部成功或全部回滾。版本衝突及低於預留庫存均拒絕，不產生半套結果；重複送出不重複異動。
- 集中盤點僅變更數量，保留效期及可售確認；未知效期仍需於單筆盤點補齊。
- 設定包含匯入、備份、商品對應、完整操作紀錄及庫存總覽。匯出入口提供既有價目表與發票商品檔，不新增不存在的庫存 Excel 匯出。
- 正式營運資料只做讀取驗證；測試進出貨與盤點使用隔離資料庫。
