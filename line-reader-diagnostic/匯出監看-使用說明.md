# LINE 新留言匯出測試版

由你啟動的本機工具：聊天區有穩定畫面變化時操作「儲存聊天」，再比對匯出文字檔，只輸出新增的記錄。原始基準聊天檔不會被刪除。沒有操作庫存或建立正式訂單。

## 第一次使用

1. 雙擊 `Start-Export.cmd`。不要同時執行先前 OCR 監看或其他 LINE 自動操作工具。
2. 自行開啟 LINE 的獨立社群視窗，停在最新留言，關閉右上選單；將視窗完整放在同一個螢幕內。
3. 在工具中按「重新整理」，選完整社群名稱。初次基準預選專案根目錄的 `[LINE]菜騎鴨-生鮮蔬果冷凍食品南北雜貨.txt`；如果要換社群，先按「選擇基準檔」選擇該社群的匯出檔。
4. 按「取得預覽（5秒）」，倒數內切回 LINE，滑鼠移開右上角的選單鈕。
5. 回到工具，在預覽上**拖曳框選訊息區域**。包含新訊息會出現的位置，排除頂端公告與底部輸入框。
6. 按「標記右上 ⋮」，在預覽上點選 LINE 的三點選單鈕。綠圈應標在三點按鈕上，藍框應在訊息區。
7. 按「開始監看」，切回 LINE，停止操作滑鼠鍵盤至少 5 秒。第一輪會先匯出一次，補抓既有基準之後的留言。
8. 後續每 2 秒檢查畫面；畫面連續兩次相同，且與上次已處理畫面不同，就觸發匯出。若持續變動達 10 秒，也會嘗試匯出，避免訊息太密集而一直等不到穩定畫面。兩次匯出至少相隔 10 秒。切回其他視窗會暫停偵測。

工具會自動操作滑鼠開啟選單，以 Windows 本機 OCR 唯一辨識「儲存聊天」，再點擊；**訂單內容直接讀文字檔，不經 OCR**。支援辨識有向視窗外延伸的 LINE 所屬彈出選單。

接著只在同一社群所屬、可核對的 Windows 標準儲存對話框中填入工具產生的新檔名並按儲存。不使用 Enter、不輸入聊天框。若 LINE 採用不同儲存介面，會停止，保留當時視窗供你檢查。這部分尚未在目前 LINE 上實測。

**畫面變化不是新留言事件。**貼圖動畫、捲動、反應數等也可能觸發一次匯出；沒有新增記錄時不產生新批次。不要把此工具當成保證完整的即時訂單來源。

## 如何保留新內容、清除重複內容

每個社群的資料保存在 `data/export-monitor/<社群識別碼>/`。

| 檔案或資料夾 | 用途 |
| --- | --- |
| `最新新增留言.txt` | 最近一次**有新增**的批次，內容只有新增記錄；零新增不會清空它 |
| `新增留言/` | 每批新增留言的 TXT／JSON，保留已收集的新內容，不重複附加整份歷史 |
| `state.json` | 唯一一份目前比對基準，保留匯出原文和順序；程式重啟後沿用 |
| `work/` | 當次完整匯出暫存，以及最近一次選單辨識證據 |
| `events.jsonl` | 匯出與比對的結果、錯誤記錄 |

流程是「完整匯出 → 確認寫入穩定 → 比對 → 保存新增批次 → 原子更新基準 → 刪除本工具這次下載的完整暫存檔」。不會刪除 LINE 訊息，也不會刪除使用者原有聊天檔。

要判斷新舊，需要保留 `state.json` 這一份內部完整比對基準；它不會每次新增一份完整備份。`work/last-menu*` 是最近一次選單截圖／OCR 證據，每輪覆寫，不持續累積。成功後清除完整暫存檔；失敗或內容對不上時保留，方便查漏。

## 比對規則

- 使用日期、時間及整段原文的**排列順序**比對，不單純以文字雜湊去重，也不只用時間當游標。
- 同一分鐘、同一個人、相同內容再次追加，若是舊記錄之後的新一筆，仍保留。
- 訊息內的換行、數量符號和名字空白保留。匯出格式未明確分隔姓名與內文，這版不猜測姓名邊界，不解析正式訂單。
- 正常完整匯出以先前記錄作為前綴；若新檔前段已截短，需要至少 3 筆可唯一對齊的連續重疊記錄。
- 出現缺段、短於原本進度、無法辨識的格式、疑似收回／修改或重疊有歧義時，停止並保留原基準與輸入。不能將這些情形一律當成沒有新留言。
- LINE 文字匯出未提供本工具可用的唯一訊息 ID，所以順序對齊也不是絕對保證。尤其整段相同留言重複、同分鐘密集留言、正文模仿時間標頭等情況，仍需人工核對。
- 每批輸出使用由新舊狀態產生的固定識別碼，重跑及中斷後重試不會另建同一批。`CompletenessVerified=false`、`OrdersCreated=0` 始終保留。

## 暫停與故障

- LINE 不在最前方、被其他視窗遮住、最小化、尺寸變動或使用者正在操作電腦時，不開始點擊。操作中若滑鼠移動、視窗失焦、按鈕核對失敗，會停止。
- 按「停止」或關閉視窗會取消後續操作；已在執行的本機 OCR 最多等候 30 秒，之後不再點擊。已產生的待處理匯出檔會保留。
- 若 `work` 有上次留下的 `incoming-*.txt`，不會直接跳過它重新開始。按「比對手動匯出檔」選該檔核對；成功後只清除工具自己產生的完整暫存檔。
- 外部手動匯出的檔案也可透過同一按鈕比對；工具不刪除外部原檔。對不上時請保留 `work` 和 `state.json` 供檢查，不要盲目重設基準。
- 改變視窗大小或螢幕縮放後，要停止並重新校準。不要讓電腦休眠或長時間停在舊留言；本工具不會捲動補載歷史，也不讀串文。
- 若未看到標準儲存視窗，可能是 LINE 直接存入其他位置或使用了不同對話框；目前會停止，而非擅自搜尋整台電腦或猜位置。
- 資料只保存在本機，不連網，不使用 OpenAI API，不需 API Credits。截圖及原文可能含客人資料，資料夾已排除 Git 追蹤。
