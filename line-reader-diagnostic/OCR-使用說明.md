# LINE 一般留言 OCR 測試

用本機 Windows 繁體中文 OCR，持續保存指定社群「主聊天室可見的一般留言」。這是讀取驗證工具，尚未切分完整訊息、辨識作者或建立訂單。

## 開始

1. 雙擊本資料夾的 `Start-OCR.cmd`。這是新工具，原本 `Start.cmd` 仍是 UIA／MSAA 診斷。
2. 在 LINE 自行開啟**獨立社群視窗**，停在最新訊息，保留顯示姓名和時間的空間。
3. 回到工具，按「重新整理視窗」，選完整社群名稱。只叫「LINE」的主視窗不接受校準，因為無法核對目前聊天室。
4. 按「取得預覽（5秒後）」，在倒數內自行切回該 LINE 視窗，保持不被遮住。預覽只存在工具記憶體中。
5. 回到工具，在左側預覽**拖曳框選留言區**，排除公告、側欄和底部輸入框。框選區域需包含留言者和時間，至少 40 × 40 像素。
6. 按「開始每 3 秒監看」，再切回 LINE。保持指定視窗在最前方，訊息停在最新位置。
7. 查看結果時切回工具，擷取會暫停。按「開啟結果資料夾」查看保存的截圖、文字和 JSON；按「停止」結束。

也可先按「測試現有圖片」，不用操作 LINE 即可驗證一張既有截圖。只啟動程式不會自動開始截圖。

## 行為與限制

- 使用 Windows 已安裝的繁體中文 OCR。本機已實測存在 `zh-Hant-TW`，不需要 OpenAI API 或下載模型。其他電腦若未安裝會顯示錯誤，不會自行安裝語言包。
- 每 3 秒檢查一次，辨識工作未結束時不會重疊執行。相鄰兩張**像素完全相同**才略過；畫面變動便重新辨識。
- 這是畫面去重，**不是訂單去重**。每張都保留當時可見的全部文字；捲動畫面可能再次讀到同一留言。不同客人的相同「+1」不會依文字相同而刪除。
- 原圖保留，另產生最多 2 倍放大的 OCR 輸入圖，最長邊限制 2500 像素。JSON 的字詞座標對應 `.ocr-input.png`；除以 `Scale` 可換算回原圖。顯示文字只移除中文字之間的空白，OCR 原文仍保留在 JSON。
- 會核對視窗 handle、LINE 程序、程序啟動時間、完整標題、前景視窗、尺寸和遮擋。切到其他視窗、最小化或偵測到遮擋時暫停；返回符合條件的畫面可恢復。改變視窗大小或螢幕縮放後需停止並重新框選。
- 使用螢幕像素擷取，LINE 必須完整放在同一個螢幕內。遮擋檢查是擷取前後的狀態檢查，不能保證排除瞬間出現又消失的浮動內容。
- 不點擊、不輸入、不自動捲動、不開串文、不讀剪貼簿、不連網、不操作庫存系統。你自行開啟聊天室所造成的已讀行為由 LINE 決定。
- 沒顯示的訊息無法讀取。快速洗版、停在舊留言、休眠或被遮住的期間可能漏讀；`events.jsonl` 記錄觀察到的暫停狀態，但不是完整性保證。
- 每次最多保存 500 張變動畫面後停止，避免持續增加磁碟用量；不自動刪除舊檔。截圖與原文均可能含客人資料，僅保存在本機且已排除 Git 追蹤。
- 辨識失敗會停止並保留原始截圖；單次 OCR 超過 30 秒會終止本工具的辨識子程序，不影響 LINE。

## 結果位置

`data/ocr/<時間-隨機碼>/`

- `session.json`：選定視窗、框選區域與設定。
- `events.jsonl`：開始、暫停原因、畫面未變、辨識及停止狀態。
- `frame-*.png`：框選區域的原始截圖。
- `frame-*.ocr-input.png`：送入本機 OCR 的放大圖。
- `frame-*.capture.json`：擷取時間、來源視窗與畫面雜湊。
- `frame-*.ocr.json`：原文、字詞位置、語言和圖片比例。
- `frame-*.txt`：方便閱讀的文字。

`CompletenessVerified=false`、`OrdersCreated=0` 是刻意保留的界線。報告不能當成已完整接單。

## 已做的驗證

2026-10-03，在這台電腦用使用者先前提供的 456 × 679 截圖，實際執行 Windows OCR 與工具的圖片辨識流程。放大 2 倍後可讀到「韓國麝香葡萄」「大陸妹」「履歷水蓮」「生豆包」等商品；`*1` 仍可能被讀成「鬥」，`g` 可能被讀成 `9`。**目前不足以無人核對數量。**

14 項離線檢查涵蓋視窗身分、框選邊界及座標換算、連續畫面去重、失敗後重試、返回舊畫面的保留及相同文字不誤刪。已編譯並測試圖片 OCR；即時 LINE 截圖與新訊息監看仍待使用者啟動後實測。沒有把既有圖片測試當成即時讀取成功。

技術參考：[Microsoft Windows OcrEngine](https://learn.microsoft.com/en-us/uwp/api/windows.media.ocr.ocrengine)、[Microsoft OCR sample](https://github.com/microsoft/Windows-universal-samples/blob/main/Samples/OCR/cs/OcrFileImage.xaml.cs)。
